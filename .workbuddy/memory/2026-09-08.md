## 午前：Middle「号」错乱 — CY2==游戏；真根因=nibble 端序

### 用户输入
- 图：CY2 里 bin「号」错乱、游戏「9号」同错、Middle.bdf「号」完整。
- 纠正：别信 memory 里「CY2 摆法伪影」；**CY2 显示与游戏一模一样**。
- 再补图：CY2 @偏移 `1F400`、宽8 高16、GBA 4bpp，网格里「号」与其它字同系扭曲 → 生成 bin 逻辑有问题，勿纠结地址。

### 排除 / 误判链
1. **GLM「CY2=查看器伪影」**：错误（用户钉死 CY2==游戏）。
2. **跟风「tile 序 TL,TR,BL,BR vs TL,BL」**：错误。`pack_slot16_4bpp` 与 GetGlyph/`chs_rasterize` 同为 **TL,BL,TR,BR**；按列序+「高 nibble=左」解包，「号」与 BDF 墨迹一致。
3. 「BDF→bin 6807 全等」假闭环：cmp 用了与错误 packer **相同的高=左**约定，自洽不等于 GBA/CY2 正确。

### 真根因
- `scripts/build_chinese_font.py` `pack_slot16_4bpp`：`(left<<4)|right` → **左=高半字节**。
- 标准（GBATEK / CrystalTile2 GBA4bpp / `blend_row_4bpp` / `extract_cols`）：**左=低半字节**。
- 结果：相邻像素对调 → CY2 与游戏同乱；BDF 源正确。
- 2026-08-31 MEMORY 已写「注释 left=high 过时、字库应低=左」，**代码未改到本次**。

### 已修（程序，未代打 ROM）

- 同步解压/预览：`engine._decompress/_compress_4bpp_glyph`、`sim_gba_font_blit`、`font_panel`、`fonts/font_tools/view_font_chs.py` + `check_font_layout.py`。

### 铁律补记
