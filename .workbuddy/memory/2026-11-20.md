## 10:10 火红方案移植：数据层打通，但撞 UI 布局墙

**上一轮崩溃的真根因（不是栈太小）**：`ldr r3, =0x08039F24` 少写 `|1`，
`bx` 到偶数地址让 CPU 切 ARM 模式 → 把 Thumb 字节当 ARM 指令 → 跳飞。
**铁律：所有 `ldr r3, =0x08xxxxxx` 必须 `|1`。**

**第二个坑**：`0x0803B11C` 硬编码 `cmp r1,#10`（最多 11 字节），
第 12 字节被强写 FF → 3 汉字名的第 3 字丢失。
3 个调用者共享（0x08037D06 队伍 / 0x0803FC68 / 0x0811CA60），
不能直接放宽（队伍路径 dst 后紧跟 nickname[10]）。
**解法：hook 里自实现拷贝**（表基址 + species*24，逐字节到 FF）。

**数据层已完全打通（GDB 实证）**
- `NickHookMid` @0x08800066：species 282 → `f7 00 05 7d f7 00 0e cf f7 00 05 91 ff`（火焰鸡 3 字完整）
- `NickAfterCopy` @0x08042444：目标 `0x0202362C` = `fc 02 02 | 火焰鸡(完整) | ff`

**但画面坏了**：血条里只剩一个「级」字，`Lv:24` 被推走。
原因：`0x08042452` 之后的排版（血条/Lv/HP 定位）依赖固定布局，
名字从 5B 变 13B 后基准没跟着变 → 全错位。

**结论**：火红能这么做是因为它整个 UI 按字符格排版（11×11、步进 13）。
红宝石血条按固定 5 字节槽设计，塞 13 字节必然撞坏后续元素。

**三条路**：A 缩短译文(2字仅12%，不可行) / B 改排版基准(工作量大) /
C 只扩名字区(中等) / D 维持现状2字(零风险)。

**已回滚**：game.bin 9568B、0x08042430/0x08042436 均原版、127 帧正常。

**保留资产**：两级跳模板、0x081B504C 空洞、NickFullName_entry.s（数据层已验证正确）、
SpeciesDump / NickHookMid / NickAfterCopy 三个探针。

## 11:16 BUG-9 修复：textMode 3 屏幕行列直写

**现象**：存档确认框右上角日文残字（まぁりがとぅ），只画上半 3 行。
判据：save f020 区域 (165..205,118..126) 墨量 origin=0 / 修复前=55 / 修复后=10。

**根因**：`grid_tile()` 对所有非 buffered 非 tm0 窗都用 tm1 网格公式
`TB+2+(row&7)*62+2*col`；而 tm3 原生是 `TB+2+col+30*row`（反汇编 0x080034E0）。
tm3 的 row 实测 **1..17 连续**，`(row&7)` 必然回绕。

**反汇编要点**：0x080034E0 里 `row*15<<1 = row*30`，**30 = 屏幕 tilemap 宽**；
最后 `lsls r1,#5` + `ldr r0,[r3,#12]` 说明返回的是 **VRAM 字节地址**。

**GDB 实测**（Tm3WinDump 新探针，428 条）：单窗 0x0202E658、TB=0x0001、
tileData=0x06008000、tilemap=0x0600F800、native 最大 533=17*30+23（精确吻合）、col 最大 28。

**实现**：新增 TM3_SCREEN_W=30 / TM3_SCREEN_H=20 / tm3_tile_of() / tm3_row()；
grid_emit 里 tm0 分支后插 tm3 分支（结构照抄 tm0 直写），grid_load 的 phase 分支同步补。

**⚠️ 铁律**：tm3 不能套 `GRID_TILE_LIMIT(0x1F0)` —— 它不占 arena，
native 合法值到 533；用 0x1F0 拦会把 row≥16 丢掉。边界是 600 格屏幕容量。
**tm3 的 row 用 curY+curTY（不右移）**，不能用 grid_row()（那是 tm1 的 >>1）。

**验证**：save 33 帧、battle_full 127 帧、battle_dialog 314 帧，全部正常无崩溃。

**新增探针** Tm3WinDump @0x080032F8：只报 textMode==3 的窗，输出
TB/TOFF/curX/curTX/curY/curTY + native 与 grid 两种公式的 tile 与差值。
