## 事实：美版汉化 ROM 的真实基线（勿被卡带代号骗）

**`work/_us_cn.gba` 是基于「美版 Pokemon Ruby 1.1 (AXVE)」汉化的，
但它把卡带代号改成了 `AXVJ`（日版代号），文件名叫 `_us_cn` 也容易误读。**

判定依据（2026-11-25 实测，前 8MB 逐字节比对）：

| 候选基线 | 与 _us_cn 相同率 |
|---|---|
| 日版 `POKEMON_RUBY_AXVJ00.gba` | **4.31%** |
| 美版 US(1.0) | 30.91% |
| 美版 1.1 | **95.16%** |
| 美版 1.2 | 95.16% |

1.1 与 1.2 只差 4 字节，用这 4 处定版：
`0xBC=02`、`0x919B=DB`、`0x91BF=DA` 全与 **1.1** 一致（1.2 是 `01/DD/DC`）。

**铁律：判断 ROM 基线必须做内容比对，不能看 0xAC 的卡带代号、
也不能看文件名。代号和文件名都可能被人为改过。**
