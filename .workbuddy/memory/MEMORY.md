## 铁律：禁止未询问就改翻译

**任何翻译文本（字、词、句、名字）都不能自己改。**
遇到显示不下、字形糊、编码冲突等问题，**必须先把实测数据摆给用户，问用户要改成什么**，
不能自作主张换成别的字（例：2026-11-23 擅自把「蛋」改成「卵」，用户明确禁止）。

## 铁律：渲染层改动的验证门槛

改完必须跑完整场景矩阵：
开始菜单、队伍、背包、商店、图鉴、对话、存档、战斗（dialog/full）。
只跑 2-3 个场景就交付 = 必然漏掉大范围回归。
