## B02 — 战斗台词（重新定性）

### 你的纠正（重要）

- 遇敌不是「多打一个首字残留」，而是整句里**后面的字被顶掉/截断**（应为「野生的×××出来了」一类）。
- 放技能后仍**无限出字卡死**。

### 机制（仍高置信）

战斗展开把物种/招式槽 `F9 op hi lo FF` **拷到中间时丢掉槽末 FF**，父串变为：

`前缀 | F9 op hi lo | 后缀… | FF`

`PrintNextChar` 一遇 `F9 op` 就 `redirect` 到 PhraseTable；短语自己的 `FF` 被原版当成**整窗结束** → 后缀永远不印（=「顶掉」）；等待提示不到 → 战斗文本任务可能空转狂打。

`GetStringWidth` 已对短语 `index+4` 续走；打印未对齐。StyleLeft 样式1 仅 1px，解释不了整段缺失。

### 已放弃（禁止再走）

| 尝试 | 结果 |
|------|------|
| ROM `.bss` PhraseResume | 无效 |
| 全量整句内联 | 地名炸 |
| IWRAM resume + 切流 | 地名炸；战斗仍坏 |
| **B02b** 父串续打才内联 | 地名微顶；战斗截断/狂打仍在 → **已撤回** |

### 下一候选 B02c（未做）

**在战斗串写入 WRAM 时展开**（`BattleStringExpandPlaceholders` / 物种名·招式名拷贝点），把 `F9 op hi lo` 展成 Phrase 体内 `F9 00×N`（不含短语 FF），再拼后缀。  
`print_next_char` 保持原切流，供地名等「整槽即整句」使用。

成功标准：遇敌整句完整；出招不狂打；地名/存档不回归。
