  3. **IWRAM `0x0203FFF0` PhraseResume + 逐字切流 + peek FF pop**（2026-08-09）→ 地名再次顶框；战斗残字/狂打**仍在**。说明「只补 resume」或该 IWRAM 槽不可用/根因另有其物。
