# AXVJ 模块地址区间台账

> 版本对照：Meowth-AXVJ **0.4.5**（0.4.6 擅自改旧已回滚；台账仅作区间记录）  
> 约定：ROM 文件内偏移（非 `0x08……` 总线地址）。名表为固定表；剧本/UI 为文本体所在带。  
> **勿随意改已挖模块的 `addr_bands` / 表基址**——新内容另开模块或挂到既有 category。

## 4. 维护规则

1. **新挖**优先：新 category + 新模块 ID，或只往现有模块的**针列表 / 表常量**加项。  
2. **禁止**为单句再写死单地址政策；区间/形态规则进 policy / modules。  
3. 改 dump 模块带 / `addr_bands`：走解包侧测准流水线（[`G3宝可梦解包/README_addr_bands.md`](../../../G3宝可梦解包/README_addr_bands.md)），再拷 `translate/modules.json`；并同步本台账有意义的区间说明。  
4. 名表基址以各作 table / inject 配置为准；本文件是人读台账。  
5. 屏上残留日文 / 乱码先登记 [`PENDING_TEXT_JP.md`](PENDING_TEXT_JP.md)，再决定扩 lexicon 还是扩 dump 带。
