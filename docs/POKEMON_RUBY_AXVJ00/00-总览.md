## 1. 一句话现状

- **引擎**：`F7 00` 双字节汉字 + 12px 自绘，全 ROM 只有一个文本入口——`PrintNextChar@0x080032F8` 整函数接管。
- **渲染**：`textMode 0` 已线性落址（战斗/菜单/招式正常）；`textMode 3` 的存档框数字乱码（BUG-9）**已修**（回绕行存储列改按需折半区）。
- **数据**：`translate/texts.json` **27 模块 / 12,193 条**；注入 8,141 条。
- **产物**：32MB，静态验收 19 PASS / 1 FAIL（`Small ink 8x8`，非运行故障）。

## 3. 未修 / 待办

1. **BUG-10**：出招画面撕裂/底部黑带——**已定位为采集侧遇敌分叉**（非渲染缺陷）。
   修前修后黑带区间完全相同（帧 73..132）；钉同 RNG 复测两侧同对手时黑带 0%。
   `battle_move_anim.lua` 已改为「每格钉同一 RNG」的确定性遇敌。
2. ~~**BUG-11**：存档确认句第一行右侧多出残字~~ → **已修（11-23）**。
   行尾 5 格旧表项未清 + 「现」字的拆分 tile 落在那批槽上。
   修法：`grid_clear_row_tail()` 在 `0xFE` 时清「光标右侧连续指向公式区」的表项。
   8 场景回归零变化。
2. **BUG-6 日文残留**：玩家名（存档内，主菜单显示 `1?4`）、领航员标题/底部——用户已定「暂缓」。
3. **摘要页状态行**：显示「在 101号状态遇到」，「道路」二字缺失（运行时拼接串，`\FD` 占位换地名）。
4. **领航员训练家之眼右列**：名字前有残留笔画（与 BUG-6 同源，暂缓）。
5. 地点名/训练家名扫描边界各漏 1 条尾巴（低危）。
6. `Small ink 8x8` 验收项：需确认 8px 小字库本征高 8 是否符合设计。
