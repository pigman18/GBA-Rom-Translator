# 战斗信息译文问题清单（2026-11-27）

> 用途：用户反馈「日版汉化的战斗信息翻译得乱七八糟」。本清单只列**实测证据**，
> 每条都有条号 + 日文原文 + 当前译文 + 判定理由。待用户定夺后再改。

## 0. 先排除一个误判

我一开始把译文里的 `\n` / `\p` 当成 BUG（统计出 276 条「含字面量」），
但查 `src/meowth/control_codes.py` 第 18-19 行确认：

```python
_DEFAULT_PARAGRAPH_CODES = ("\\.", "\\p")   # \p = 翻页
_DEFAULT_STRIP_LAYOUT   = ("\\l", "\\n")    # \l \n = 换行
```

**`\n` / `\p` / `\l` 是这套文本系统的合法转义符，不是损坏。**
实测画面（f095）显示「バシャーモ怎么办?」正常，也印证了这一点。

## 1. 系统性错译：`ひるむ` 译成「麻痹」

`ひるむ` = 畏缩 / 害怕（faint attack 类效果）
`まひ` = 麻痹（paralysis，一个独立状态）

两者是**不同的战斗状态**，混淆会导致玩家误判战况。

| 条号 | 日文原文 | 当前译文 | 应为 |
|---|---|---|---|
| 1906 | `いりょくの たかい こうこうわざ\nこうげきを もらうと ひるむ` | `…受到攻击时会陷入麻痹` | 畏缩 |
| 4937 | `せんせいこうげきで ひるませる\nさいしょの ターンにしか つかえない` | `用攻击使对手陷入麻痹…` | 畏缩 |
| 5812 | `てきを おどろかして こうげき\nてきを ひるませることがある` | `有时会使对手陷入麻痹` | 畏缩 |

同类需核对（`ひるむ` 出现在下列条目附近）：4845、4847、5812、4973、10423

## 3. 语义结构破坏（断句位置错）

原文用 `\n` 分段是有语义的（一句一行），译文把句子切断在奇怪的位置。

| 条号 | 日文原文 | 当前译文 | 问题 |
|---|---|---|---|
| 7254 | `ほのおの いきおいと ねっぷうで いかくする。\nすばやい みのこなしで あいての こうげきを\nかわしながら どうじに ほのおで もやす。` | `…以敏捷的身手躲开对手\n攻击的\n同时用火焰将其烧尽。` | 「对手攻击的／同时」断在半句 |
| 7838 | `むごい しうちの うさばらしに\nてきを ぜんりょくで こうげき` | `为了发泄遭受残酷对待\n的怨恨,\n全力攻击对手。` | 「对待／的怨恨」断开 |
| 6158 | `どうしますか？` | `想做什么?` | 原意「要怎么做？」，语气偏差 |
| 8617 | `を どうしますか？` | `要如何处理?` | 缺主语衔接（此条是拼接用半句，需看上下文） |

## 4. 待用户决定的问题

1. **`\p`（翻页）用得过多**：很多原本一屏能显示完的短句被强插 `\p`，
   玩家要按 A 才能看下半句，节奏碎。是否统一收敛？

2. **`ポケモン` 译法**：现统一「宝可梦」。美版汉化用「宝可梦」还是别的？
   需对比确认。

3. **战斗提示语的一致性**：例如
   - `こうげき！` → 「攻击!」
   - `\00の こうげき！` → 「\00的攻击!」
   两条句式不同（一条无主、一条有主），但日文原文也是这区别，属正常。

4. **`わざポイント` 译法**：条 372 译成「招式威力」（错，应是「招式点数」=PP），
   但条 4361/8404 译成「招式的剩余点数」（对）。**同一术语两种译法**。
