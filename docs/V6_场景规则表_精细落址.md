# V6 场景规则表：精细落址（条件分字号 + 每行固定基址）

> 2026-09-01。参考 `bak/text-v4/text_scene.c` 的 `kOptWindow` 精细算法，
> 但**不做 v4 的逐窗登记重流程**（WinCfg + kWindows[] + gen/check 脚本），
> 只保留必要字段，落地一套轻量声明式「场景地址 + 条件 → 字号 + 行基址」。

## 1. 目标

用户拍板两点：

1. **条件驱动分字号**：用「场景地址（tpl）+ 条件（curX）」决定不同区域用不同
   字号绘制，省 tile。例：设置菜单左侧 key 标签用 16px、右侧 value 候选用 12px。
2. **精准排列**：同一个 win 窗口内，tile 按「每行固定基址 + 行内偏移」确定性
   排列，重绘幂等，不再全局高水位乱领。

**边界（已确认）**：分区独立——16px 区（key）在前、12px 区（value）在后，
不任意混排（16 是 8 的倍数 phase 恒 0，key 区结束 phase 归 0，12px 区从 0 续）。
任意混排（16↔12 交错）需三段式渲染，留作后续。

## 2. 数据结构（PrintNextChar_hook.c）

```c
struct V6Zone { uint8_t cx_hi; uint8_t font_px; };   /* curX < cx_hi → 字号 */

struct V6SceneRule {
    uint32_t tpl;             /* win[0x00] 模板地址 = 唯一键 */
    uint8_t  row_y0, row_shift;   /* r = (curY-y0) >> shift */
    const uint16_t *row_tab;  /* 每行 tile 基址（[1..row_n]） */
    uint8_t  row_n;
    const struct V6Zone *zones;
    uint8_t  zone_n;
};
```

## 3. 三条查表 + 两处落地

| 函数 | 作用 |
|---|---|
| `v6_scene_lookup(tpl)` | 按模板地址查规则，未命中返 0 |
| `v6_scene_font(rule, curX)` | curX 分区 → 字号（key 16 / value 12） |
| `v6_scene_row_base(rule, curY)` | curY → 行基址（clamp 到 [1,row_n]） |

**落地两处**：

- **条件分字号**（`chs_print`）：命中规则 → `fontSize = v6_scene_font(curX)`；
  否则默认 12px。
- **精准排列**（`print_glyph_px` / `chs_place` 16px 分支）：
  - 命中规则：`tile = 行基址 + (px>>3)*2`（px 是 ChsPhase 的行内像素游标，
    12px 相位共享 / 16px 整格都基于它，确定性、重绘幂等）。
  - 未命中：`v6_alloc_tile()` 全局高水位（回退）。

16px key（命中规则）走整格 2 列，`tile = 行基址 + (px>>3)*2 + col*2`，每字
4 tile，`px += 16` 保行内偏移连续。

## 4. 已登记场景（样板）

| tpl | 行定位 | 行基址 | 分区 |
|---|---|---|---|
| `0x081BB874` 设置菜单 | `r=(curY-3)>>1` | `0x33/0x8D/0xAD/0xCD/0x101/0x121/0x121` | curX<8 → 16px key；其余 → 12px value |

行基址沿用 v4 `kOptRows` 实测值，若 v6 下撞引用字形，按 gdb 重采调整。

## 5. 新增场景步骤

1. gdb 采该窗口的 curY 集合、每行候选字数、引用字形 tile 号。
2. 在 `kV6Scenes[]` 加一条 `V6SceneRule`（行基址 + 分区字号）。
3. 重编 + 打包 + 实测（撞引用字形就调行基址）。

## 6. 与「空闲 tile 不可知」的关系

本方案的行基址是**人为划定的固定 tile 区间**（赌官方不引用），是
`结论_替换BUG真正难点_空闲tile不可知.md` 中「方案 A1 窗口独占 charBase」的
降级版——不是整窗独占，而是**窗口内每行独占一段**。牺牲通用性换确定性。
未登记窗口仍走全局高水位（方案 B 治标），两套并存。
