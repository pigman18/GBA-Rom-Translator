# A2.8 事故复盘：stride 改动漏改乘法站点

> 2026-11-04
> 严重程度：**高**。导致技能名空白、背包黑屏。

---

## 一、事故现象

用户实测：
- **华丽大赛技能界面**：技能名空白（只显示 PP，名字没了）
- **背包**：黑屏

---

## 二、根因

我改了 6 张表的 stride，但**每张表只改了 1 处乘法指令**，
而实际上每张表有**多处**引用站点，每处都有自己的 `index×stride` 乘法序列。

### 实测的乘法站点数

| 表 | 字面量站点 | 被 ldr 引用 | **乘法站点** | 我改了几处 |
|---|---|---|---|---|
| 招式名 | 43 | 43 | **40** | **1** ❌ |
| 道具名 | 14 | 14 | **14** | **1** ❌ |
| 秘密基地装饰名 | 22 | 22 | **22** | **1** ❌ |
| 图鉴分类名 | 7 | 7 | **5** | **1** ❌ |
| 属性名 | 4 | 3 | **3** | **1** ❌ |
| 特性名 | 3 | 3 | **3** | **1** ❌ |

**合计需改 87 处，我只改了 6 处 —— 漏了 81 处。**

### 为什么会导致空白/黑屏

未改的站点仍按旧 stride 计算元素地址：

```
招式名：新表 stride=32，但 39 处代码仍算 base + idx*8
  → 读到新表中间的错误位置
  → 解出来是垃圾字节/NUL
  → 技能名显示空白

道具名：新表 stride=80，但 13 处代码仍算 base + idx*40
  → 背包读道具名越界
  → 黑屏
```

## 三、我犯错的环节

`a2_gen_final_patch.py` 里我写的是：

```python
# 只取第一个 ldr
insns = list(md.disasm(rom[off:off + 2], off))
ins = insns[0]
```

`off` 是**单个**指令地址（`0x02B538` 等），我当时只从
`a2_base_refs.py` 的输出里挑了「第一个站点」，没有遍历全部。

`a2_emergency_check.py` 才是正确做法：
遍历所有字面量站点 → 对每个找 ldr → 检查 ldr 前的乘法 → 全部改。

## 四、正确做法

### 必须遍历全部站点

```python
for lit in find_literal_sites(rom, base + GBA_BASE):
    for ldr in find_ldr_for(rom, lit):
        mul_insns = find_mul_before(rom, ldr)   # 找乘法
        for ins in mul_insns:
            if ins 是决定 stride 的那条 lsls:
                patch(ins.address, 新移位量)
```

### 难点：不是每处乘法都长得一样

从 `a2_emergency_check.py` 的输出看，各站点的乘法形态不同：

```
招式名 0x02B538: lsls r1, r1, #3                      ← 标准
招式名 0x047806: lsls r1, r1, #3                      ← 标准
招式名 0x06C3B0: lsls r1, r1, #3                      ← 标准
道具名 0x0A538C: lsls r0, r0, #3                      ← (i*4+i)<<3
道具名 0x0A53B0: lsls r1, r1, #3                      ← 同上
图鉴   0x08C1D4: lsls r0, r0, #2                      ← (i*8-i)<<2
图鉴   0x08D58E: lsls r4, r4, #2                      ← 同上
装饰名 0x0AF2D6: lsls r0, r0, #2                      ← 同上
```

大部分形态一致，但有些站点的「乘法」被我脚本识别成了别的指令
（如 `lsls r0, r0, #0x10` 那是 16 位截断，不是 stride 乘法）。
**需要更精确的判据：只改「结果寄存器参与后续加基址」的那条 lsls。**

## 五、教训

1. **改动前必须确认「所有生效点」**，不能只改一处就以为改完了
2. **多条引用必然有多个乘法站点** —— 字面量有几处，乘法就有几处
3. **改完必须验证全部站点**，不能只验证一处
4. 用户实测是对的：bot 只跑了 `pokemon_menu` 和 `battle`，
   **没跑华丽大赛和背包场景**，所以没发现
