## 二、这次成功的关键

| 环节 | 做法 |
|---|---|
| **找站点** | 扫 `= base+0x08000000` 的 u32 → 找 ldr 引用 → 3 个（确定） |
| **求 stride** | 符号执行算出每站点 K=8（**确定值，不是猜**） |
| **定位指令** | `Lin` 记录「产生该 K 的那条移位指令」（精确） |
| **改写** | 只改这 3 条 `lsls` 的立即数 3→5 |
| **新表** | 77 项 × 32 字节，同名区扩展到 32B |
| **重定向** | 3 处字面量 → 新表 |
| **验证** | bot 实测显示「猛火」 |

**全程没有一个环节靠推测。**
