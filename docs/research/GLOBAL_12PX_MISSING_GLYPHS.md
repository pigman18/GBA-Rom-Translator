## 1. 期望正文（注入侧，已证）

### 1.1 模块策略

`texts.json` → `图鉴说明`：

- `word_count: 16` → 中文实折约 **15** 字/行（`chs_word_count_for_width_px`）
- `wrap_pages: false` + `max_lines: 3` → **抹平种子里的 `\p`/`\n`，只插 `FE`，不插 `FB`**

### 1.2 种子 vs 折行产物

| 层 | 内容 |
|----|------|
| 缓存/种子 | `据说,充足的营养和阳\n光\p会让它的花色变得更加\n鲜艳。\p花的香味能抚慰人心。` |
| `wrap_text(..., wrap_pages=False)` | `据说,充足的营养和阳光会让它的\n花色变得更加鲜艳。花的香味能抚\n慰人心。` |
| `translate.build.json` `target_hex` | **FE×2，FB×0，FF×1**（已核对） |

期望三行：

| 行 | 字数 | 文本 |
|----|------|------|
| L1 | 15 | 据说,充足的营养和阳光会让它的 |
| L2 | 15 | 花色变得更加鲜艳。花的香味能抚 |
| L3 | 4 | 慰人心。 |

### 1.3 与屏对照（关键）

| 行 | 期望 | 用户屏 | 判定 |
|----|------|--------|------|
| L1 | `据说,充足的营养和阳光会让它的` | 以 **`慰人心。`** 开头 + 残笔 + `的营养和阳光会让它的` | **FAIL**：缺「据说,充足」，且混入 L3 |
| L2 | `花色变得更加鲜艳。花的香味能抚` | 同期望 | PASS |
| L3 | `慰人心。` | 同期望 | PASS |

结论：**不是漏译 / 不是 `\p` 翻页残留进 ROM**（注入无 FB）。  
是 **绘制期** 把 L3 墨迹映到 L1 格，并弄丢/削掉 L1 前段。

## 2. Origin 路径（图鉴说明）— 已钉死

### 2.1 谁打 / 打哪

对照 pret `pokeruby` `Task_InitPageScreenMultistep` case 4（美版几何；日版同调用形）：

```c
Menu_PrintText(gPokedexEntries[dexNum].descriptionPage1, 2, 13);
```

| 项 | 值 |
|----|-----|
| 谁 | `Menu_PrintText` ← `Task_InitPageScreenMultistep`（JP `0x0808C040`，内 `bl Menu_PrintText@0x0806F16C` ×5） |
| 窗 | `gWindowTemplate_81E7064` → JP `0x081B7B0C`；`Text_LoadWindowTemplate` + `InitMenuWindow` |
| 坐标 | **left=2, top=13** → 三行 tile Y = **13 / 15 / 17**（FE 后 CTY+=2） |

| 分类名 | `UnusedPrintMonName`（P07）— 本 BUG 无关 |

### 2.2 几何 → band（H1 铁证）

| 行 | tile Y | `grid_row` | 自然 band | `grid_band`（旧：band0→**6**） |

## 3. 引擎现状（当前 `PrintNextChar_hook.c`，调研快照）

| 规则 | 范围 | 对图鉴说明的含义 |
|------|------|------------------|
| `grid_tile = TB+2 + band*62 + 2*col` | 全局 | 12px 本征分配 |
| `grid_band`：`band0 && ty≥14 && CURSOR_X<20` → **5**（曾误用 6） | 对话左缘 | 信息框 band0..4；图鉴 L1=band6，映 6 会踩 L1 |
| 12px 占用 → **仅背包 skip** | `grid_is_bag_list` | 图鉴**不再**因占用跳字（训练家修复点） |
| 12px 占用 → **仅对话 find_free** | ty≥14 且 cx<20 | 图鉴多半不走；占用时 **直接写本征** |
| `GRID_TILE_LIMIT=0x1F0` 则整字不写 | 全局 | 高 band / 宽行可能静默缺字 |
| FE/FF 对话 `blank_rest`：像素宽起 Blank→right=26 | 仅 ty≥14 且 1&lt;cx&lt;20 | 清预载假名碎点；禁 CURSOR_TILE_X / right=28 |
| `0x00` 只推进不重绘 | 全局 | 短清长依赖 Blank/重打，不靠空格擦 VRAM |

训练家列表「暂时好了」= 去掉**全局 skip** 的直接收益。  
图鉴仍坏 = **同一网格公式下的另一条失败模式**（更像 **跨行踩本征 VRAM**，而不是 skip 留洞）。
