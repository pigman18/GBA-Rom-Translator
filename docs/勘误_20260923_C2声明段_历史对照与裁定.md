# 勘误_20260923 — C2 声明式段：历史对照与裁定

> 触发：用户质疑「声明式画布段以前做过，效果特别差连最基础的字都显示不出来，你确定可以？」。
> 复核结论：**用户记忆正确。今日（0923）两份文档把 C2「升级为默认主路线」的判定收回**。
> 本文档固化考古证据、错误定位与裁定，防止再打转。

---

## 1. 历史考古（全部有据可查）

| 时代 | 做法 | 结局 | 根因 | 证据 |
|---|---|---|---|---|
| v0–v2（08 月下旬） | 借 `win[0x18]` 做线性分配 | 三轮 BUG：行间碎片 / 持久游标铺满全屏 / 槽轮转串换 | 线性分配与 tm1 会话结构冲突（每选项=独立 ITP 会话，游标载体每会话被清） | `评估_20260829` 决策 3 |
| v4 / v4.1 | 「偶数槽安全」静态段 | **全屏"1"、持续恶化** | `lower=upper+0x100` 算术误读（N1 推翻：实为 +1），中文搬到字模下半行 tile 直接毁字模 | `评估_20260829` N1 |
| v5–v8 | 「安全块 [121,322]」静态段 | 串字 / 纯色方块 / 透明格子 | **B1：引用稀疏 ≠ 占用稀疏**——图集写满 [1,513)，那 202 tile 上压着 128 个真字形 | `复盘_20260829` §3 B1/B6/B7 |
| v6/v7 静态选址 | tile 基址/避让带进场景表 | **早已废弃** | 同 B1 类（静态知识断言占用） | `hook/include/scene_cfg.h:5` 头注释自证：「v6/v7 静态选址时代的产物，早已废弃」 |
| 08-31 例外条款 | `kTm1Windows` 声明式配置表（逐窗登记空闲段） | **从未实施**——`hook/src` 全树无 `kTm1Windows`，无任何声明式段表代码 | 只停留在 `REWRITE_DESIGN §4.1` 设计稿 | grep 证据（2026-09-23） |

**关键澄清**：用户记忆里「做过且效果特别差」的是 **v4–v8 时代的静态段布局**（把中文塞进 tm1 图集 charblock 的静态区间）——这正是「声明式/静态登记空闲段」的同族做法；而 08-31 的例外条款（本轮被引用为 C2 依据）**从未落地实施过**，不是先例，只是未验证的设计条款。

## 2. 今日 0923 分析的错误定位

1. 把 `评估_20260829` N4'「设置页 22 字模仅占 44 tile，安全块 [121,322]」当 C2 的「实测先例」引用——
   该前提**恰被同日复盘 B1 证伪**（N4' 的"安全"是「靠字符稀疏+重绘自愈侥幸」，评估自己的风险表 R1 已标注）。
2. 「图集整 cb 被占但引用稀疏 → 逐窗声明画布段」的推论与 v5–v8 死因**同构**。
3. 违反项目既定方法论：「引用集类清单必须标注采集来源与完整性」「不得带着未关闭风险合入」。

## 3. 公平性说明（今天与当年的实质差异，记录在案）

- 图集已停用（停图集 hook `0x080029E0→mov r0,#1;bx lr`）：v5–v8 时代「每格下压字形」的条件在当前构建不复存在；
- 现行 v9 已实机证明该区域可写中文：活引用位图 + VRAM 非空校验 + ours 段表三闸门，**当帧事实零预测**（`tile_alloc.c`）。
- 因此死因不是「区域不可用」，而是「**用一次性静态知识断言 VRAM 占用**」。声明式若要活命，必须靠当帧闸门兜底——
  而那样它相对现行 v9 没有任何增量收益（静态表只是给 v9 提供一个偏好基址），反而多一套会腐烂的知识。

## 4. 全网佐证（0923 两轮调研 + pret 源码复核）

- 成活引擎**无一使用静态声明段**：pret mode2 在 `Text_InitWindow` 开窗时按 `2+w×h` **运行时**分配；
  Mother 3 vwf、pokeRS/D 商全部是「开窗运行时分配 + 所有权 + 生命周期」。
- 公开世界的答案与 09-09 用户裁定（唯一路线＝复刻美版 VRAM 分配器）完全一致。

## 5. 裁定

1. **C2 否决**（作为主路线与独立路线均否决）。
   唯一存活的声明式形态＝现行 `scene_cfg` 档位表——**只管字号、不管 tile 落址**，且逐窗实机截图验收。
2. **主路线回到 B（美版契约四件套，阶段 2/3）**：画布分配 / BGxCNT 重排 / 图集装载 / UI 窗接管一次做全。
   与 `docs/禁止_避让带与抬水位_只认VRAM分配器.md`（09-09 用户裁定）一致。**C1 维持冻结**。
3. S1~S7 静态勘测清单与 G1~G3 gdb 金标**仍然有效**——它们服务 B 的按家族迁移，不服务 C2。
4. 若未来确需给某窗最小改动私有区，只允许「声明段 + 三闸门当帧校验、失败回退 v9」的**从属形态**
   （本质=v9 的偏好基址提示），且逐窗 gdb+实机验收；不作为路线存在。

> 一句话：**「声明式画布段」在 v4–v8 已经用实机事故证死过一次，08-31 条款是没实施过的纸面例外；
> 本轮把纸面条款当先例复活，是错误。路线回归四件套。**
