## 二、原生表项定位公式（0x08003708 GetCursorTilemapPointer 反汇编定案）

```
idx   = u8(win[0x1D] + win[0x1C]) + u8(win[0x1B] + win[0x1A])
entry = template[0x10] + 2 * idx          ; template+0x10 = tilemap 指针
upper = [entry]  lower = [entry + 2字节]   ; 对为水平相邻两表项
```
- 表项值 = tile 号 (低 10 位) | palette (12-15 位)
- **列游标 = win[0x1B] + win[0x1A]**：我们写 win[0x1B]=tx0+(px>>3)，win[0x1A]=窗左缘恒定

## 五、实测重绘算法（选项页，2152 条写入还原）

1. 进页：全屏渲染 2 轮（39 + 41 条写入，覆盖 cells 36-41/164-184/239+ 等）；
2. 稳态：**每数帧重绘同一 7 格行**（cells 175,176,179,180,181,183,184；
   cx+tx 恒 15,16,19,20,21,23,24 → win[0x1B] 每轮归零），实测 **297 轮不停止**；
3. 每轮 tile 落点在 3-4 个空隙间轮转（0x16C→0x174→0x1CA→…）→ 同格不同 tile
   = **闪烁根因**（gdb 前写法：重锚后扫描跳往新隙）；
4. 修复（slot_new==2 → 原地复用 scr_org）：同字形写同 tile、表项重写同值，
   幂等零闪烁——**已实测闪烁消失**。

## 六、实测重绘算法（详情页，802 条写入还原）

- 36 个 placement 段 = 页面由**大量独立小打印**组成（标题 cells 1-9、
  区块头 cells 26-28/139-143、数值行 cells 149-152/373-388、EXP 行等）；
- 每段独立扫描定隙 → 落点随 live 状态漂移（0x100/0x124/0x134/0x15C/0x16C/
  0x192/0x19C…）；段间 cell 覆盖差异 → **未覆盖格残留上一段表项 = 叠字/替换**；
- 例：段0（24 条，cells 66-454）→ 段1（7 条，cells 142-156）：
  段0 独有 cells 66-68/139-141/203-205/386-391/452-454 的表项未被子段覆盖
  → 段0 字形残留可见。
