# 设置页：划界之外的候选方案（2026-09-23）

前提（用户裁定，不回滚 softbuf）：
- 当前 softbuf（skip 图集 + 30×16 公式格）实机仍碎，与「假划界」观感同类。
- **不再**用「改不改 e6f0 / 真假划界」当主叙事。
- 设置页真实链路：`DrawOptionMenuChoice` → `MenuPrint(text, x, y)` → 多次 Init/Print；**同一行 3 个候选不同 x**（慢/普通/快）。

美版对照（emerald `option_menu.c`，公开源码）：
- `FillWindowPixelBuffer` → `AddTextPrinterParameterized` → `CopyWindowToVram`
- 是**窗像素缓冲整页拷**，不是日版 tm1 共享图集 + 逐字领 tile。

---

## 候选（互斥优先序，供你点名）

### S1 — 按次软缓冲（真·接近 Mother2，但挂在 MenuPrint 调用上）

- **做什么：** 每次 `DrawOptionMenuChoice` / `MenuPrint` 开一块 **仅本串** 的 EWRAM 1bpp/4bpp 条带（宽≈字数×步进，高 16），画完再按本次 `(x,y)` flush 到 VRAM。
- **不做：** 全局 30×16、不改 TLWT 返回值、不 skip 整页图集（或仅本串涉及格清写）。
- **为何不同于现 softbuf：** 现方案是「整窗一块网格，多串抢同一 col 公式」；S1 是「一串一缓冲」，对齐设置页「一行多次 Print」。
- **风险：** flush 落点仍要钉死 `(x,y)→tilemap 格→tile 号`（文档里已写须 gdb，未做）。

### S2 — 设置页强制小字 / 固定步进（不碰开窗）

- **做什么：** 设置 tpl 强制 8px/9px 小库 + 更紧步进，继续走现有 v8（或关掉 softbuf 只对设置），减少 tile 用量与相位跨列。
- **不做：** TLWT/Multistep/公式格。
- **代价：** 观感变小；不保证领航员。
- **依据：** 撞车主因之一是 12px 半列 + 多串同窗；小字是汉化圈常用「控预算」手段（L0/L1），不是划界。

### S3 — 禁用 softbuf，修「跨串相位/尾列」污染

- **做什么：** 设置页仍 v8；每次 `MenuPrint`/`InitTextPrinter` **强制 `v8_phase_reset` + 清 last_tile**；或按 `(tpl, y, x0)` 分相位槽，禁止「普通」串复用「慢」串尾列。
- **依据：** 截图右列叠「普/通/声」+ 尾花块，很像 **相位/尾列跨串复用**，不一定是「没占够矩形」。
- **风险：** 治叠字；若根因是 atlas 槽耗尽，仍会撞。

### S4 — 选项字改 OBJ 叠字（仅设置候选列）

- **做什么：** 左标签可仍 BG；右「慢/普通/快」用 OBJ 字模条。
- **不做：** 改 e6f0 / 图集 skip。
- **风险：** OAM 数量、优先级、滚动；设置页行数少，预算尚可。

### S5 — 固定选项图片字（L0c）

- **做什么：** 「文字速度 / 慢 / 普通 / 快」等烤进 tile 图，MenuPrint 对这些串短路。
- **代价：** 只罩固定 UI；扩展差。作止血可以，不作全文引擎。

### S6 — 整页像素窗（emerald 式）移植到日版设置

- **做什么：** 设置场景单独 `FillWindowPixelBuffer` 类缓冲 + 一次 CopyWindowToVram。
- **最像美版设置不撞的原因**；工作量最大，等于换该场景文字子系统。
