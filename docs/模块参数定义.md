# modules.json 模块参数定义

> 定位：`configs/<ROMAJE>/translate/modules.json`
> 本文件是**读取侧**唯一事实来源。写入/回写行为由 `modules.inject.json`（开发者维护）决定，不在此声明。
> schema: v3。新增游戏只改配置，不增 pipeline 代码。

## 顶层结构

```jsonc
{
  "_meta": {
    "schema": "v3",
    "rom_id": "POKEMON_RUBY_AXVJ00",
    "game_code": "AXVJ"
  },
  "modules": {
    "<module_id>": {
      // 通用字段，见下
    }
  }
}
```

## 模块级通用字段

| 字段 | 类型 | 必填 | 含义 |
|------|------|------|------|
| `type` | str | 是 | 读取规则（见下表）。决定「起始怎么来」，非函数名。 |
| `start` | 单地址 或 `[["lo","hi"],…]` | 视 type | 起始。单区间=单地址；多区间=`[["lo","hi"],…]`。 |
| `end` | 地址 | 部分 type | 终止地址，仅单区间时使用。 |
| `read` | obj | 部分 type | 该 type 特有的提取参数，**不放区间**。 |
| `label` | str | 否 | 展示名。 |
| `group` | str | 否 | 分组。 |
| `description` | str | 否 | 描述。 |
| `default` | bool | 否 | 是否默认参与。 |
| `hidden` | bool | 否 | true=仅作采集源/中间结果，不直接对应用户词条。 |
| `geo_ranges` | `[["lo","hi"],…]` | 否 | 地理范围（dump/回写地址用）。 |

> 说明：`write`、归组过滤（`keep_any_contains`/`classify_rules`/`module_by_original`/`content_class`/`default_module`）均**不属于**读取侧 `read`，属 inject 写回阶段。

## type 一览（9 种）

| type | read 参数 | 含义 / 启发式 |
|------|-----------|----------------|
| `scan` | — | 在 `start` 区间顺序扫字节（兼容原 `addr_bands`）。最常用。 |
| `stride` | `stride`: int | 定距取槽。`start`~`end` 每 `stride` 字节取一条。 |
| `prefix` | `prefix`: [str,...] | 固定前缀字节（如 FC），区间内命中为起点。支持多前缀。 |
| `needle` | `seed_originals`: [str,...] 或 `content_class` | `seed_originals` 编码后区间内 find。 |
| `pointer` | `min_ptr_source` 等 | 全 ROM 解 4 字节指针→跳目标读；或固定指针站。 |
| `ptr_stride` | `stride`(应为4) | 指针表：每 4 字节取槽→读指针→再解引用。 |
| `struct` | `entry_size`,`name_stride`,`desc_ptr_offset` | 结构体表：按 entry 切，内部取名称 / 描述指针。 |
| `desc_table` | — | 说明指针表：起始为指针数组→各说明目标文本。 |
| `addr_bands` | — | 过时兼容名，等价 `scan`，保留解析不报错。 |

## 与既有迁移映射

| 原 type | 新 type |
|---------|---------|
| `addr_bands` | `scan` |
| `fixed_table` | `stride` |
| `ptr_table` | `ptr_stride`（`stride`=4） |
| `struct_table` | `struct` |

## Ruby 现状（v3 迁移后）

- 共 48 模块：`scan`×34 / `stride`×4 / `ptr_stride`×1 / `struct`×1 / `needle`×4 / `prefix`×3 / `pointer`×1。
- `scan`（原 `addr_bands` 34 个）的 `start` 已从多 band 迁移为顶层 `[["lo","hi"],…]`；`read` 不再含 `addr_bands`。
- 8 个 hidden 模块用于采集 enrich 数据源：`选项菜单扫描`/`FC彩窗扫描`(prefix)、`存档提示扫描`/`战斗HUD采集`/`短标菜单采集`/`状态背包采集`(needle)、`战斗提示扫描`(prefix)、`主脚本指针`(pointer)。
