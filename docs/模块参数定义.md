# texts.json 模块 / 样式参数定义

> 定位：`configs/<ROMAJE>/translate/texts.json`
> 源配置：`src/util/configs/<ROMAJE>.yaml` 的 `texts.styles` / `texts.modules`（list，`- id:`）。  
> 本文件是**读取侧**唯一事实来源。写入/回写行为由 modules 的 `write`/`word_count`/`style`（开发者维护）决定。
>
> **`word_count`**：一行汉字上限（整数，默认 14）。配置只写这个；中文折行时**代码**按 12px 步进 + 16px 字模自动换算实折字数（窗宽≈`word_count×12`，再扣字模右边），避免行末句号被裁。图鉴说明实测填 **16**（实折约 15）。旧字段 `line_width` 已废弃。**短菜单/UI 不要过小**（曾设 3 →「关闭背包」被切开）。  
> **`wrap_pages`**：对话默认 `true`（满两行插 `\p`）。商店/道具/图鉴说明设 `false`（只 `\n`，因 `FB` 在说明窗不翻页）。配合 **`max_lines`**（典型 3）截断；此类模块会先抹平种子里的 `\n`/`\p` 再按 `word_count` 重排。  
> schema: v3。新增游戏只改配置，不增 pipeline 代码。

## 顶层结构

```jsonc
{
  "game_id": "POKEMON_RUBY_AXVJ00",
  "styles": {
    "<style_id>": {
      "left": 2          // 可选：整体左移 px；F9 第二字节按序自动 01/81/02/82…
    }
  },
  "modules": {
    "<module_id>": {
      // 通用字段，见下
    }
  }
}
```

yaml 与 modules 同形（list）：

```yaml
texts:
  modules:
    - id: 宝可梦名
      write:
        type: op
        op: "0x01"
```

## 短语通道（write.type=op，样式机制已移除）

| 字段 | 类型 | 必填 | 含义 |
|------|------|------|------|
| `write.op` | int | 否 | 模块短语引用的 F9 第二字节（`0x01..0x7E`）；缺省 `0x80`。 |

hook：`op == 0` → 旁载；`op == 0x80` → PhraseTable 且清 sticky；其它 → PhraseTable + sticky。  
宝可梦名 = **`F9 01 hi lo`**；起笔左移量由 hook 常量 **`CHS_NAME_PHRASE_LEFT`** 写死（game.h），不再有 `StyleLeft[op]` 表 / `styles_data.asm`。

**ROM 数据（不进 game.bin）**：

| asm | 来源 | 固定址 |
|-----|------|--------|
| `phrase_data.asm` | `translate.build.json` → `phrases` | PhraseOffsets `0x08810000` / PhraseTable `0x08820000` |

改短语正文：重生 asm + armips 即可；**仅 C/hook 逻辑变更时才重编 `game.bin`**。

**废弃**：`styles.channel`；`CreateMonName` 钩子 / `StyleDexNameLeft`；`write.type=op` / `write.op`；模块顶栏 `left`（改挂 styles）；compile-time `layout_left.h` px。

## 模块级通用字段

| 字段 | 类型 | 必填 | 含义 |
|------|------|------|------|
| `type` | str | 是 | 读取规则（见下表）。决定「起始怎么来」，非函数名。 |
| `start` | 单地址 或 `[["lo","hi"],…]` | 视 type | 起始。单区间=单地址；多区间=`[["lo","hi"],…]`。 |
| `end` | 地址 | 部分 type | 终止地址，仅单区间时使用。 |
| `read` | obj | 部分 type | 该 type 特有的提取参数，**不放区间**。 |
| `label` | str | 否 | 展示名。 |
| `group` | str | 否 | 分组。 |
| `description` | str | 否 | 描述。 |
| `default` | bool | 否 | 是否默认参与。 |
| `hidden` | bool | 否 | true=仅作采集源/中间结果，不直接对应用户词条。 |
| `geo_ranges` | `[["lo","hi"],…]` | 否 | 地理范围（dump/回写地址用）。 |
| `word_count` | int | 否 | 一行汉字上限（折行）；默认 14。中文由代码按 12/16 字模自动换算实折。 |
| `wrap_pages` / `max_lines` | bool / int | 否 | 对话翻页与截断行数。 |
| `translate_rules` | `[str,…]` | 否 | LLM 附加规则（按模块分批翻译时追加进 system 提示编号）；**不参与 inject**。 |
| `style` | str | 否 | 引用 `styles` 里的 id（如 `图鉴`）。短语通道与 `left` 由此派生。 |
| `left` | int（px） | 否 | **已废弃**；请用 `style` → `styles[].left`。 |

> 说明：`write`（名表 widen 等）、归组过滤均**不属于**读取侧 `read`，属 inject 写回阶段。`write.type=op` 已废弃。

## type 一览（9 种）

| type | read 参数 | 含义 / 启发式 | inject_body | F900 越槽升 F980？ |
|------|-----------|----------------|-------------|-------------------|
| `scan` | — | 在 `start` 区间顺序扫字节（兼容原 `addr_bands`）。最常用。 | **trusted_ptr** | 否（整串 F900 + relocate） |
| `stride` | `stride`: int | 定距取槽。`start`~`end` 每 `stride` 字节取一条。 | **fixed_slot** | **是** |
| `prefix` | `prefix`: [str,...] | 固定前缀字节（如 FC），区间内命中为起点。支持多前缀。 | **trusted_ptr** | 否 |
| `needle` | `seed_originals`: [str,...] 或 `content_class` | `seed_originals` 编码后区间内 find. | **trusted_ptr** | 否（hidden enrich） |
| `pointer` | `min_ptr_source` 等 | 全 ROM 解 4 字节指针→跳目标读；或固定指针站。 | **trusted_ptr** | 否 |
| `ptr_stride` / `stride_ptr` | `stride`(应为4) | 指针表：每 4 字节取槽→读指针→再解引用。 | **trusted_ptr** | 否（改指针 + reloc 目标体） |
| `struct` | `entry_size`；可选 `eos`/`suffix`（默认 `FF`）、`desc_ptr_offset` | **结构体行表**（≠ `type=stride`）：`entry_size`=整行步长；名称从行首读到后缀；`byte_length`=原文实际长。勿配 `read.stride`。AXVJ 道具：`entry_size: 40`。 | **fixed_slot**（按原文长） | **是** |
| `desc_table` | — | 说明指针表：起始为指针数组→各说明目标文本。 | **trusted_ptr** | 否 |
| `addr_bands` | — | 过时兼容名，等价 `scan`，保留解析不报错。 | **trusted_ptr** | 否 |

### inject_body（由 type 派生，不逐模块手写）

- **fixed_slot**：正文写在定长槽内。`F9 00` 编码长度 > `byte_length` 时自动升短语短引用（默认 `F9 80`；有 `style` 则用分配码）。Ruby：`属性名`/`特性名`/`物种名`/`招式名`（`stride`）、`道具名`（`struct`）。
- **trusted_ptr**：正文可由可信指针改写到扩展区。越槽**不**自动升 F980；保持整串 `F9 00`（+ PCS 控制符），由 `reloc + pointer patch` 承接。剧情/设施/界面/说明等 `scan`、以及 `性格名`（`stride_ptr`）均属此类。

实现：`meowth.modules.module_is_fixed_slot`；仅 fixed 参与 engine「自动进 F9 80」。lexicon 多字整句进短语表是词库去重，与「升槽」无关。

## 与既有迁移映射

| 原 type | 新 type |
|---------|---------|
| `addr_bands` | `scan` |
| `fixed_table` | `stride` |
| `ptr_table` | `ptr_stride`（`stride`=4） |
| `struct_table` | `struct` |

## Ruby 现状（v3 迁移后）

- 共 48 模块：`scan`×34 / `stride`×4 / `stride_ptr`×1 / `struct`×1 / `needle`×4 / `prefix`×3 / `pointer`×1。
- `scan`（原 `addr_bands` 34 个）的 `start` 已从多 band 迁移为顶层 `[["lo","hi"],…]`；`read` 不再含 `addr_bands`。
- 8 个 hidden 模块用于采集 enrich 数据源：`选项菜单扫描`/`FC彩窗扫描`(prefix)、`存档提示扫描`/`战斗HUD采集`/`短标菜单采集`/`状态背包采集`(needle)、`战斗提示扫描`(prefix)、`主脚本指针`(pointer)。
- **F980 自动升槽**仅 `stride`+`struct`（属性/特性/物种/招式/道具名）；剧情等 `scan` 不升。
- 样式示例：`styles.图鉴`（首个 → 自动 `F9 01`，`left: 2`）；`宝可梦名.style: 图鉴`。
