# 全网 GBA 汉化：汉字显示路线调研（补完版 · 2026-09-23）

约束：**坚持日版 ROM 为底**。  
本文第二轮补检索后重写分类；承认首轮把「市场成片手段」收得太窄。

---

## 0. 对「就这些？」的诚实回答

**不是只有三条。** 全网公开资料里，GBA（含 GB/GBC 同构）汉化画字的手段更多，但可以压成一张「手段表」。  
缺的是：**没有**公开、可对标美版增益的 **AXVJ（日版红宝石本篇）文字引擎级** 开源；不等于全世界只有「软件缓冲 / 迁美版契约 / 扩字库」三种。

首轮漏掉或写轻了的（本轮补上）：

| # | 手段 | 公开出处量级 |
|---|---|---|
| 1 | 完全码表：SJIS/自定义表内**替换字模**，译文卡长度 | 经典教程海量（CrystalTile / WQSG） |
| 2 | **子集字库**：用有限汉字顶掉原假名/汉字槽（不扩引擎） | Mother3 工具说明；入门教程 |
| 3 | **图片字 / 图块汉化**：菜单标题烤进贴图，不走字库 | EMU618「GBA图片汉化」等 |
| 4 | **多套字库**各自扩容（对话 / 菜单 / 取名） | 光明之魂2 教程；黄金太阳双字库工程 |
| 5 | 只改 **GetStringWidth / 对齐**，绘制已能出中文 | pmcenter 绿宝石增益对齐帖 |
| 6 | **双字节 + hook 打印**（增益类） | Wokann 美版增益；Mother2 CHS |
| 7 | **整段 VWF/软件缓冲** 替换打印 | jeffman Mother2；Tonc TTE |
| 8 | **对话开窗预留槽 + WRAM 拼字灌 VRAM** | 老男人 GB/GBC 圣剑/11×11 系列 |
| 9 | **ROM 扩容 + 指针 repoint**（为长译文腾地，不解决 VRAM） | 月谣教程；Meowth(pypi) 描述 |
| 10 | **反编译改源码** 再编 ROM | pokeemerald-Chinese 等 |
| 11 | **日版底成片**（非宝可梦本篇） | Mother3 漫游；黄金太阳2024日版新汉化；弹珠台/小新(Wokann)；FFTA 熊组日版 |

**仍未在公开成熟成片中找到当主架构的：** 高水位 / 避让带 / 空闲区扫描。

## 1. 按「动哪一层」分类（比按游戏名更准）

### L0 — 不动引擎：字模/贴图/长度

| 手法 | 做什么 | 日版底？ | 对 AXVJ 设置/领航员 |
|---|---|---|---|
| L0a 完全码表替换 | 字模换成汉字，码点仍 SJIS/原表；译文 ≤ 原文长 | 是（多数日版 SJIS 作） | 假名区≠共享图集抢位；**挡不住** Gen3 UI 图集撞车 |
| L0b 子集顶槽 | 有限汉字盖原槽；Mother3 官方工具也承认 font space 极紧 | 是（Mother3 仅日版） | 字数不够 Gen3 全文；且不解决落址 |
| L0c 图片汉化 | CrystalTile 找 VRAM/OBJ 图 → 改像素 | 是 | 只适合固定 UI；对话/动态名不行 |
| L0d 强行缩短/换行 | 人工控宽 | 是 | 治标；设置页多字段仍撞 |

### L1 — 改读码/宽度，尽量少动绘制

| 手法 | 做什么 | 日版底？ | 对 AXVJ |
|---|---|---|---|
| L1a 双字节判定 + 指针步进 | hook 打印循环认两字节一字 | 是（Mother2-chs；日版小新/弹珠台同类） | **必要但不充分**：还要解决「字画在哪」 |
| L1b 宽度表/GetStringWidth | 居中、右对齐、换行算对 | 是（可移植到日版地址） | 只修排版；不修撞 tile |
| L1c 多字库表扩展 | 对话一套、菜单一套各自扩 | 是（光2、黄金太阳双 font） | Gen3 多 font 已有；**主矛盾仍是共享图集所有权** |

### L2 — 改「字落到哪块 VRAM」

| 手法 | 做什么 | 公开标杆 | 对 AXVJ |
|---|---|---|---|
| L2a 骑原作窗/base-tile 契约 | 开窗一次拿 span，窗内公式落址 | **美版** Gen3 增益全体 | 日版缺这套契约 → 要么迁契约，要么换 L2b/L2c |
| L2b 软件缓冲整段替换 | EWRAM 1bpp blit → 4bpp 写回；坐标归自己 | Mother2 EN/CHS；Tonc | **日版底可行**；工作量≈新文字引擎 |
| L2c 开窗预留槽 + 动态灌字/拼字 | 生命周期=对话框；11×11 提高密度 | GB/GBC 老男人系列 | 对「有私有窗区」场景有效；**tm1 共享图集**要对症改开窗，不是扫空闲 |
| L2d OBJ 叠字 | 字画在 OBJ VRAM | 教材多、成片汉化少见作主路径 | 128 OBJ 上限；密集 UI 紧 |
| L2e 位图 Mode 直接画 | Mode3/4 刷像素 | 家用/demo；正式汉化少 | 与 Gen3 tile UI 不兼容 |

### L3 — 换底座

| 手法 | 说明 |
|---|---|
| L3a 美版 ROM + 增益（含「J 版」皮） | 市场 Gen3 主答案；**违反日版底** |
| L3b 反编译中文 | 美版 emerald 系；**违反日版底** |

## 2. 日版底「已做成片」的外部证据（本篇外）

这些证明「日版底 + 中文」在 GBA 上成立，但**引擎不可直接贴到 AXVJ**：

1. **Mother 3（仅日版）** — 漫游&空气汉化；工具链见 [mother3.fobby.net/tools](https://mother3.fobby.net/tools/)（英文补丁工具 + font editor + asm hacks）。中文成片存在，技术细账公开少，但底座是 **JP ROM + 改字库/脚本注入**，不是美版。  
2. **黄金太阳 开启的封印 2024 新汉化** — 发布帖写明 **基于日版原版**；流程文本/名/图全汉；程序仍有边角问题。公开技术细节少；乌克兰语工程展示「双 4bpp 字库 extract/inject」可对照结构。  
3. **Wokann 日版开源** — [弹珠台 RS](https://github.com/Wokann/PokemonPinballRubySapphire_CHN)、[蜡笔小新电影乐园](https://github.com/Wokann/GBA_CSc_AoYCnD_chs)：armips 自研字库程序。  
4. **FFTA 日版汉化（熊组等）** — 成片早于美版迁移工具；[ffta_us_cn](https://github.com/BSoD123456/ffta_us_cn) 是「日版汉化 → 美版」搬运，侧面证明日版先有完整字库。  
5. **火影 RPG 等** — [gba-narutorpg-chs](https://github.com/suhli/gba-narutorpg-chs)：8×8/8×16 字模 + mapping 写回（偏 L0/L1）。

**AXVJ 本篇：** 全网检索仍 **无** 与美版增益对等的开源文字引擎；贴吧/pmcenter 提到的「红宝石半汉化」标注为 **(US)** 或「J 版=美版程序」。

## 3. 在「坚持日版底」下，真正可选的分叉（按可行性）

面向你的硬问题（设置/领航员不撞），外部证据收敛到：

| 优先级 | 分叉 | 依据 | 备注 |
|---|---|---|---|
| P0 | **L2b 软件缓冲引擎**（Mother2 系） | 日版底 + 开源全链路 | 最像「另起打印」；重 |
| P0 | **L2a 迁美版窗/base-tile 契约到日版** | 全市场 Gen3 中文靠它活 | 不是测带；是移植所有权 API |
| P1 | **L2c 按窗生命周期灌槽**（开窗算 span，关窗释放） | GB 汉化系 + 美版孪生语义 | 与「假划界抬水位」相反：必须挂窗对象 |
| P2 | L0c 图片字 + L0b 子集 | 只罩固定 UI | 不能当全文方案 |
| P2 | L1a+L1b | 双字节+宽度 | 必做配套，单独不够 |
| 排除 | L3a/L3b | 美版底 | 与约束冲突 |
| 排除 | 测空闲/抬水位 | 公开成片主路径未见；本仓已证伪 | — |

## 5. 结论（给你拍板）

- 坚持日版底 → 全网可对标的硬核只有两条主线：**整段软件缓冲（L2b）**，或 **把美版那种窗所有权迁进日版（L2a/L2c）**。  
- 其余（子集、图片字、扩字库、改宽度、卡长度）是 **配套或局部**，不是设置/领航员不撞的主解。  
- 「就这些？」→ **手段种类远多于三条**；**能扛住 Gen3 共享图集 UI 的公开主解，仍然只有上述两条。**
