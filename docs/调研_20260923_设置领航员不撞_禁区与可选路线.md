## 1. 问题重述（按寻址模型，不按「12px」）

| | 美版菜单主力 | 日版设置/多数菜单 | 现行汉化（回滚后） |
|---|---|---|---|
| textMode | US tm2 ≈ 窗画布 | JP **tm1** 共享图集 | 同左 |
| 开窗 | `2+w×h` 私有网格，返回下一 offset 接框 | 预渲 256×2 进图集，返回 **512** 接框 | 官方照旧 |
| 汉字落点 | 位置公式进私有网格 | 装不进 256 槽 | **v8 内容领号**（`lo≥0x100`，避图集/非空） |
| 行消耗 | ∝ 行像素÷8 | ∝ 不同字形×槽 | ∝ 每字 2～4 tile（相位） |

撞 UI 的结构原因（09-08 已写清）：**内容寻址无硬上界 = 窗面积**；邻居是图集/框/图标。  
「12px 多占 tile」是密度症状，不是根因；根因是 **tm1 没有可画的私有位置网格**。

设置页实测锚点（既有日志，非本轮新 gdb）：

- tpl `0x081BB874`，cb2，tm1，tileData `0x06008000`，tilemap `0x06007800`
- 引擎自留：图集 `[1,513)` + 框带紧随（见 `UI分配函数登记_20260910.md` §7）
- 中文可用相对区历史上落在 **≥0x100 且避开非空**（v8）；起址改到 1 必撞——已事故固化

领航员：长文 + 同 win 多 tpl 复用（`0x0202E658`）→ 内容寻址最容易饿死/互踩；Middle 字号是**密度止血**，不是划界。

## 3. 路线重新分类（只分类，不选型开工）

### A. 内容寻址改良（现行 v8 族）— **基线，不是目标终态**

- 是什么：保持 tm1 图集与官方 `e6f0=512` 接框不动；中文在校验后的空槽领号。  
- 已知：设置页曾「勉强还行」；起址/校验动错会立刻撞 UI（注释事故）。  
- 上限：领航员级长文仍可能饿死；12px 密度高。  
- **调研用途**：用 gdb+.sav 画清「勉强还行」时中文 tile 号 vs 框/图标号分布，当作回归金标——**先测再谈改**。

### B. 真位置寻址（美版契约完整移植）— **理论正确，门槛极高**

必须**同时**具备（禁止文档 §3），缺一不算：

1. 预算挂在**当次窗**  
2. `2+w×h` 来源可证伪（日版实测几何，不是随手 30×16）  
3. 同一次开窗把「文字段结束」交给**框装载**，用后清除，且**框图形尺寸与新 budget 一致**  
4. 落址窗内公式，无 v8  
5. 能力页等未开画布场景不中招  

09-23 / 09-08 失败点：只做了「改下一 offset + 跳图集」，**没有**证明框装载、tilemap 引用、多路 `InitTextPrinter` 重绘与新网格一致。  
在未完成「设置页开窗全链路表（谁读 e6f0、框占几格、每行 Init 的 curX/Y、tilemap 写哪些格）」之前，**B 禁止再动代码**。

### C. 场景专用绘制（不改全局开窗契约）— **待勘测**

- 已有：`DrawOptionMenuChoice` 只管色/短语，最终仍进同一 Print 路径。  
- 候选方向（未验证）：设置/领航员**单独**绘制出口，把字画进**该场景 tilemap 已为该字符串准备的格子**（位置来自官方 MenuPrint 的 left/top），像素 blend 进这些格——**不**改 TLWT/e6f0/SetBase。  
- 风险：tm1 官方这些格原本指向图集字形；改写 VRAM 内容会毁掉假名图集槽（若同屏还要日文）或与其它引用共享槽的窗互踩。  
- 须先 gdb：设置页一行「对话速度」的 tilemap 条目是什么号、是否独占。

### D. 换渲染介质（OBJ / 另一 BG）— **远景，非近场**

- Tonc OBJ 文本：与官方菜单精灵争 OAM。  
- 独占 BG：需空闲 layer + 与 DISPCNT 调度不冲突。  
- 无 Gen3 日版菜单先例 → 标【远景】，本阶段不排期。

### E. 只缩字号 / 改译躲裁切 — **明确不是「不撞」解**

- Middle/Small 可减密度；**不**产生所有权。  
- 改译躲裁切：项目禁令。

## 4. 本轮调研结论（可执行）

1. **「美版怎么做 12px」调研本身没有错；错在把「位置寻址」偷换成「改 e6f0 占 span」。** 后者已两次实锤死刑，移出候选。  
2. **当前唯一不诈尸的可玩基线仍是 A（v8 内容寻址 + 官方开窗契约不动）。**  
3. **若要坚持验收「不撞」终态，只剩 B 或可能的 C；二者都要求先勘测、后代码。** B 的勘测清单见下；未完成清单禁止再提「画布开工」。  
4. 全网仍无日版 AXVJ 可抄作业。
